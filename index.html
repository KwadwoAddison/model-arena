VI — Method & notes

How the scoring stays honest.

  1. Blind. Identity is stripped before grading. The grader sees an answer, never an author.
  2. Deterministic first. Code executes against held-out tests; arithmetic is checked numerically. Prose faces a published rubric only where machines can't.
  3. Par-token costing. Each task carries a budget (the median of family history). Under par earns credit. Over par loses it. Wrong answers earn nothing at any price.
  4. The reasoning sweep. Every model runs low, medium, high. The site shows all three, because the right model at low effort is often the right hire.
  5. Newcomers enter equal. Adding a model is one JSON entry. The next run scores it against identical tasks. No legacy advantage, no rookie tax beyond sample size.
  6. Thin samples are flagged, not ranked. Fewer than five graded runs in a cell earns a flag, not a podium.
